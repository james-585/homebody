## Approach
Follows ADR 0001: `node --test` for unit (no dependencies), `@playwright/test` for the real `index.html` served by `scripts/serve.mjs` (static, zero-dependency, relative URLs, random free port). Goldens are produced by `page.evaluate` against classic-script globals (`state`, `mGetLastPerformance`, etc.), stored as sorted-key JSON, and compared exactly; a `UPDATE_GOLDENS=1` env var is the only way to write them, and first recording is reviewed by hand. The clock is frozen with Playwright's `page.clock` (install at a fixed instant, fixed timezone and locale in config) before the app loads. Seeding uses `addInitScript` to set `localStorage.vaultfit_v1`, so no real profile is touched and no network is used (fonts are blocked/stubbed via route so Google Fonts is never called). Unit migration harness takes `(migrations[], fixtures[])` and checks shared invariants; it is exported so T6/T10/T12 only add migrations.

- `migrations.test.mjs` - AC5; invariants over every legacy and synthetic file; negative self-test (a deliberately lossy fake migration must fail the harness) proves the harness can fail. Also covers corrupt and future-version blobs failing safe without overwrite, via the harness contract (skipped until a runner exists, marked `todo`, not silently passing).
- Synthetic fixtures loaded by the harness - AC6; a check that each has a README entry.
- AC1 and AC7 - verified by running `npm ci && npm run verify` from a fresh clone in the scratchpad.

## Stop conditions
Stop, report, and wait for the human if any of these happen:
- The change needs a file outside **Files** above, or a new dependency.
- An existing test has to be changed or deleted to make the new code pass.
- A storage change has no migration, or a migration fails on any fixture in tests/fixtures/legacy/.
- A strength standard, MET value, volume target or other training number would have to be written without a source or documented rationale.
- A new external request, third-party script, notification, health-platform link or data source is needed, or a secret seems necessary.
- Exercise data would have to be retyped by hand rather than extracted or sourced.
- The change makes logging a set take more than two taps, or breaks offline use.
- The 'verify' command is still red after two honest attempts.
- The acceptance criteria turn out to be ambiguous or contradict the spec.
- Goldens differ between two consecutive runs after two attempts to freeze time, timezone and locale.
- Playwright browsers (Chromium or WebKit) cannot be installed in this environment.
- Characterising would require changing `index.html` (e.g. a needed global is not reachable from `page.evaluate`).
- Any fixture fact in m1.md does not match the fixture (report the measured numbers; do not edit either to agree).
- The protect-paths hook or permissions block a listed file.
