# T3 — Real offline: self-hosted fonts and full precache

Milestone: M1 (docs/plans/m1.md) · Agent: storage-sync-engineer · Branch: claude/m1-t3-offline
Status: Approved 2026-10-31

## Scope
- In: self-host Oswald and Inter (woff2, SIL OFL 1.1 texts, provenance record) in `fonts/`; replace the Google Fonts `<link>` (index.html line 16, the only external reference; no preconnect exists) with a local `@font-face` block (`font-display: swap`). `sw.js`: precache the whole shell with `cache: 'reload'` (install fails loudly if any file is missing), serve navigations from the precached `index.html`, cache-first for shell assets, and on activate delete stale `homebody-*` caches. `PRECACHE` derived from the shell file list. `docs/offline.md`.
- Out: `skipWaiting` removal, the `sw.js?v=7` registration, banners, 60 s polling and `controllerchange` reload (all T4; they stay as they are); any other `index.html` edit; storage or data changes; font subsetting or conversion by us; CLAUDE.md edits (see Q5); `src/` modules.

## Acceptance criteria
- [ ] e2e: first load online, then `context.setOffline(true)`, reload: app renders Home, fonts load (no failed requests), a workout can be logged and appears in History after another offline reload.
- [ ] e2e: zero requests to any non-origin host during a full session.
- [ ] Old caches are deleted on activate; only `homebody-<VERSION>` remains.
- [ ] Added font bytes reported; accessibility-performance-reviewer accepts the size.

## Approach
**Fonts.** Source: the Google Fonts CSS API (`fonts.googleapis.com/css2`), the same official origin the app uses today, with a modern UA so it returns woff2 on `fonts.gstatic.com`; request Oswald 400-700 and Inter 400-600. Usage found by grep: Oswald 600/700 (about 350 rules), Inter 400/500/600; Inter 300 appears nowhere, so it is dropped. Inter 700 is used inline but the old link never loaded it (browsers show 600), so the Inter `@font-face` range stops at 600 and nothing changes visually. If Google serves one variable file per family and subset (expected, to be verified), I declare weight ranges; otherwise one file per weight actually used. Subsetting stays out: I take Google's own unmodified `latin` file per family, and `latin-ext` only if the human wants it (Q1); any other character falls back to the system sans-serif. Licences: `OFL.txt` for each family from `google/fonts` (`ofl/oswald/`, `ofl/inter/`) via raw.githubusercontent.com at a commit SHA resolved with `gh api` (not `main`). Integrity: `fonts/SOURCES.md` records, per file, source URL, retrieval date, response headers used, SHA-256, and the licence file's commit SHA; the CSS response text is pasted in. Each file is checked for the `wOF2` magic and plausible size before commit. A unit test re-hashes the files against SOURCES.md; that proves "unchanged since commit", not authenticity (authenticity is the official host over TLS; the human can re-fetch and compare). Network policy here (HEAD checks only, nothing downloaded): `fonts.googleapis.com` 200 and `raw.githubusercontent.com` 200; `fonts.gstatic.com` answers (404 on a bare path), so the actual file fetch is unproven until implementation; `github.com` returns 403 (so no clone or release downloads). Nothing is substituted or converted if a fetch fails (stop condition).

**One source of truth for the cache list.** In `scripts/stamp-sw.mjs`, delete the constant `PRECACHE`; derive it from `listShellFiles` filtered to runtime types (`.html .json .png .js .woff2`), so `fonts/OFL.txt` and `SOURCES.md` are hashed but not cached. Entries stay `JSON.stringify`-escaped and pass the existing safe-path validator; an unsafe filename under `fonts/` or `src/` makes the stamper fail rather than skip. The rendered list is also fed into the hash, so changing the filter changes `VERSION` even when no file changed (today the block is stripped from the hash, which is the T2 gap).

**sw.js.** Install: `cache.addAll(PRECACHE.map(u => new Request(u, {cache:'reload'})))` with the swallowing `.catch` removed, so a partial cache never installs. Fetch (GET, same-origin only): navigations return `index.html` from the current cache (ignoreSearch), assets are cache-first from `CACHE`, a miss falls to the network; cross-origin requests are not intercepted. Activate: delete only caches starting `homebody-` that are not `homebody-<VERSION>`, then `clients.claim()`. This is narrower than ADR 0003's wording because the Pages origin is shared with other projects; I read the AC as "only one `homebody-*` cache remains" and ask the architect to note it in the ADR. All paths are relative to the SW script, so the GitHub Pages sub-path, scope and `start_url` are unchanged. **Until T4, `skipWaiting()` on install, the legacy `'skipWaiting'` message and the page's reload-on-`controllerchange` all remain.** Consequence for tests: on first install the page reloads once when the worker claims it, so e2e waits for `navigator.serviceWorker.controller` and a settled page before going offline, and no T3 test exercises updates.

## Stop conditions
Stop, report, and wait for the human if any of these happen:
- The change needs a file outside **Files** above, or a new dependency.
- An existing test has to be changed or deleted to make the new code pass (other than the golden-hash value and the optional Q4 edit named above).
- A storage change has no migration, or a migration fails on any fixture in tests/fixtures/legacy/.
- A strength standard, MET value, volume target or other training number would have to be written without a source or documented rationale.
- A new external request, third-party script, notification, health-platform link or data source is needed, or a secret seems necessary.
- Exercise data would have to be retyped by hand rather than extracted or sourced.
- The change makes logging a set take more than two taps, or breaks offline use.
- The 'verify' command is still red after two honest attempts.
- The acceptance criteria turn out to be ambiguous or contradict the spec.
- The woff2 files or licence texts cannot be fetched from the official sources above (Google Fonts CSS API/gstatic; `google/fonts` licence at a pinned commit), the response is not woff2, or a download needs a permission or network allowance I lack: never fabricate, convert, or substitute another font or mirror.
- Google returns different files per UA or weight in a way that changes the visual weights in use (compare with the weights listed above).
- Any weight or style outside the set above is found in use (for example italic), or a non-ASCII-heavy UI string needs a subset beyond `latin`.
- A step needs an `index.html` change beyond the font link and `@font-face`, or a `sw.js` change that is really T4 (update flow).
- The offline e2e only passes with a flake workaround (fixed sleeps) after two attempts.
